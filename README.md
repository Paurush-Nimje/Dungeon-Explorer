# DungeonStd



## About the Game



DungeonStd is a completed first-person puzzle-solving game developed in Unity for desktop platforms. Players must explore the environment, interpret clues, and solve interactive puzzles to unlock doors and progress through the game.



The game features four distinct puzzles, each introducing a different challenge involving code-breaking, sequence recognition, mechanical interaction, and environmental exploration.

## Key Features



\- First-person gameplay designed for desktop.

\- Four unique, clue-based puzzles.

\- Interactive numpad code entry.

\- Order-dependent button interactions.

\- Mechanical rotation puzzle.

\- Exploration-based final puzzle.

\- Puzzle-triggered door unlocking and progression.

## How to Play



1\. Explore the environment and find clues.

2\. Examine each puzzle and determine its solution.

3\. Complete the puzzle to open its corresponding door.

4\. Solve all four puzzles to progress through the game and unlock the final door.
